RAEHAN YANUAR — PORTFOLIO V1
================================

Isi folder:
- index.html
- style.css
- script.js
- assets/profile.png

CARA COBA DI HP
---------------
1. Download ZIP lalu extract.
2. Buka index.html memakai browser atau Acode.
3. Kalau memakai Acode, buka folder project lalu Preview.

SEBELUM DIPUBLISH
-----------------
Cari teks berikut di index.html:
- EMAIL_KAMU
- LINK_LINKEDIN

Ganti dengan kontak publik yang memang ingin ditampilkan.

FOTO KERJA
----------
Versi ini sengaja TIDAK memasukkan foto kerja mentah yang:
- menampilkan nama/email/nomor HP orang,
- menampilkan lokasi/timestamp rinci,
- memperlihatkan layar operasional/internal,
- memperlihatkan data OJT/evaluasi asli.

Setelah foto aman/disensor, baru tambahkan ke assets/ dan bisa dibuat galeri Journey v2.
